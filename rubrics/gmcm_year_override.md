# GMCM Year Override

```yaml
year: null
official_source: null
page_limit: null
format: null
submission_rules: null
special_requirements: null
verified: false
```

此文件只保存有官方原文或官方页面证据的当年规则。`verified: false` 时，任何字段都不得作为提交依据；未知字段保持 `null`，不得凭记忆补全。比赛项目可把核实后的副本保存在 `materials/gmcm_year_override.md`，并记录来源、核实日期和负责人。
