# 竞赛适配范围

GMCM-first v0.9 当前只以中国研究生数学建模竞赛（China Postgraduate Mathematical Contest in Modeling / GMCM / 华为杯）为主要目标。CUMCM、MCM、ICM、MathorCup 等留待以后适配；不得把本版 rubric 当作这些赛事的官方或完整标准。

每届由团队从官方来源取得赛题、附件、报名/提交规则、模板和更新通知，原件保存到 `materials/` 与 `problem_files/`。将页数、格式、匿名、提交、支撑材料和 AI 使用/披露要求写入 `materials/gmcm_year_override.md`，附来源和核实负责人；未核实字段保持 `null`。

稳定 GMCM rubric 关注逐问回答、数学实质、多问递进、真实计算、验证、结构化优化、工程意义和论文证据。它不保证获奖，也不能替代当届官方规则。三位成员都是 owner，共同决定模型与最终结论。
