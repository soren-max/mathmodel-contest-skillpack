# 竞赛适配

本工具面向 CUMCM、中国研究生数学建模竞赛/华为杯、MCM/ICM、MathorCup 及其他建模比赛。支持表示流程可复用，不代表主办方认证、符合所有年度规则或保证获奖。

每次由团队从**当届官方来源**取得赛题、报名/提交规则、模板和更新通知，原件保存到 `materials/` 与 `problem_files/`，在 `notes/bootstrap.md` 记录 URL、获取日期和适用组别。此仓库不硬编码比赛日期、页数或 AI 政策。

| 场景 | 本次需要确认的适配事项 |
| --- | --- |
| CUMCM | 赛区/组别、题号、中文数学表达、匿名与附件要求 |
| 研究生赛 / 华为杯 | 赛题数据规模、求解预算、工程解释、论文及支撑材料 |
| MCM / ICM | 当届英文写作要求、summary/附加交付、引用和 AI 使用披露 |
| MathorCup | 当前赛事具体组别、官方模板、数据与提交方式 |
| 其他竞赛 | 主办方规则优先，调整语言、目录映射、评价与交付接口 |

共同检查截止时区、命名、匿名、格式、页数、引用、支撑代码、数据权限与 AI 使用规定；将核实结果写进当前项目约定。禁止把上一届规定直接当成本届事实。清理意外的内部日志/路径时，保留官方要求的 AI 使用披露。

J/F/L 默认分工是可调整的职责模板；每人都是 owner，共同决定模型选择与最终结论。有限时间内先确保所有题目形成可验证闭环，再追求复杂度或视觉效果。
